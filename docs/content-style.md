# 内容写作约定

使用 `human-style-paper-writing` 的文字约束维护主页内容。论文摘要和专著介绍按完整段落写，短卡片、导航标签和履历字段保留网页需要的长度。

## 叙述

- 先写发生了什么，再写人物怎样应对。让笑点落在场景里，少用术语替笑点作解释。
- 正文不用破折号连接句子，也不用中英文分号。一个段落至多使用一个冒号，仅在确实引出列表或定义时使用。
- 以陈述句为主，长短句交替。英文完整句至少五词，多数控制在三十词以内。
- 论文摘要和专著介绍通常写四到八句，围绕一件事展开。首页简介保持适合浏览的篇幅。
- 删掉替自己辩解、预先回应批评和说明已删除内容的句子。改正设定后直接写正确内容。
- 避免反复使用「严格区分」「首次系统提出」「核心结论」等句式。能写成一个具体动作，就直接写动作。
- 同一细节不在相邻段落重复解释。简历可作摘要，详情页负责展开。

## 已确定的内容

- 《我的大贤者老师》中的老师是艾尔海森，由他主动为派蒙办理教令院入学。
- 保留已经确定的书名、论文名、角色名和研究方向。改变这些名称前先向用户确认。
- 内容保持角色口吻，导航、按钮、筛选、表单及各子页布局保持通用、清晰。
- 不在主页加入破坏沉浸感的说明条。图片来源与示例内容的性质记录在仓库文档中。

`npm test` 会检查叙述字段中的连接破折号、分号与冒号数量。时间范围、正式标题和元数据不参与这类正文检查。句子节奏、重复程度和角色语气仍需人工通读。
